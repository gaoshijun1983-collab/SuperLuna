# SuperLuna 双端真实项目测试交接

日期：2026-08-09
SuperLuna 候选：`0.2.0-alpha.21`
用途：Windows 端《道骨：西行路》与 Mac 端《神隐物语：最后的社务所》各完成一个真实、独立、可回传的开发切片；两端结果最终返回 SuperLuna 研发任务吸收。

## 共同原则

- 不使用外部 ChatGPT 指挥开发，不恢复旧评审 Chat。
- 不创建循环自动任务，不自动切换模型，不使用 `/goal`。
- 先读各自项目里的 `AGENTS.md`、当前状态、任务路线、相关源码与测试；本交接不能覆盖项目本地事实。
- 每端只推进一个有边界的下一步；先写失败反例或明确验收，再做最小实现。
- 自动测试只能证明本地行为，不能代替真实 Godot 图形运行和玩家体验。
- 不把两个项目的文件、状态、任务 ID、Chat ID 或测试结果互相复制。
- 最终回传必须区分：实际修改、自动测试、真实运行、合理推断、尚未验证。
